# Guide Bot

Бот для задания **Guide** в метро-тайкуне на Roblox. Сам берёт задание, находит на карте станции
Start и Goal и протягивает маршрут по одной станции за раз, пока гость не доедет. Потом ждёт
кулдаун и берёт следующее.

## Запуск

1. Открой игру в Roblox, выбери карту **с одной веткой метро**.
2. Скачай [GuideBot.exe](GuideBot.exe) и запусти двойным кликом. Python ставить не нужно.
3. Бот сам развернёт окно игры и начнёт работать.

| Клавиша | Действие |
|---------|----------|
| **F8**  | пауза / продолжить |
| **F10** | выход |

Пока бот работает, мышь занята: не двигай её и не переключай окно. Нужна мышь — нажми F8.

## Что умеет

- Открывает меню Tasks, если игра показывает обычное меню (например, после перезагрузки сервера).
- Ждёт, пока игра загрузится или перезагрузится, и продолжает сам.
- Работает на любом масштабе карты; если станция спрятана под окном задания — сдвигает карту.
- Закрывает случайные всплывающие окна (миссии, «Quit this task?»).
- Проверяет каждый перегон и повторяет его, если игра его не засчитала.

## Требования

- Windows 10/11.
- Настроено и проверено на мониторе **1920×1080** с развёрнутым окном Roblox и английским
  интерфейсом игры. На других разрешениях кнопки могут определяться неверно.
- Windows SmartScreen может предупредить о неизвестном издателе — файл не подписан.

## Параметры

```
GuideBot.exe --count 20      выполнить 20 заданий и выйти
GuideBot.exe --cooldown 10   пауза после задания в секундах (по умолчанию 10)
GuideBot.exe --debug         подробный лог и скриншоты в папку debug
```

## Запуск из исходников

```
pip install -r requirements.txt
python guide_bot.py
```

Сборка exe: `pyinstaller --onefile --console --name GuideBot guide_bot.py`

## Как это работает

Бот не лезет в память игры и ничего в неё не внедряет: он делает снимки окна, по цветам находит
кнопки, кольца Start/Goal, кружки станций и линию метро, строит путь вдоль линии и двигает мышь.

Автоматизация может нарушать правила игры или Roblox — используй на свой риск.
